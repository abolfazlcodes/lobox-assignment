# Lobox Multi Select Component

This project is a solution to the Lobox Front-end Developer assignment. It implements a reusable multi-select dropdown component with the ability to add new items dynamically.

## ✨ Features

- ✅ Built with **React** and **TypeScript**
- 🎨 Styled using **SCSS**
- ➕ Users can **add new items** by typing and pressing `Enter`
- 📋 Supports **multi-selection**
- 🔁 **Reusable** component architecture
- 🖱️ Dropdown closes when clicking outside
- 💡 UI design closely follows the provided image

## 🚀 Getting Started

1. Clone the repository
2. Install dependencies
3. Run the development server

```bash
npm install
npm run dev
```
